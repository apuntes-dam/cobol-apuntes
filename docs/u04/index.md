# U4 · Programación orientada a objetos

COBOL no tiene clases ni objetos. Lo más parecido que tiene a una unidad reutilizable con una interfaz definida es un **subprograma** (`CALL`, `LINKAGE SECTION`, `GOBACK`).

## Teoría

* [4.1 Subprogramas](01-subprogramas.md): `CALL`, `LINKAGE SECTION`, `GOBACK`, formas de pasar datos y `WORKING-STORAGE` frente a `LOCAL-STORAGE`.

## Antes de empezar: qué debes dominar

* Subprogramas: `CALL`, `LINKAGE SECTION`, `GOBACK` y el contrato entre quien llama y quien es llamado.
* Formas de pasar datos: `BY REFERENCE`, `BY CONTENT` y `BY VALUE`.
* Estado entre llamadas: `WORKING-STORAGE` (persiste) frente a `LOCAL-STORAGE` (por invocación).
* Señalar un error con un parámetro de estado, no terminando el programa desde dentro del subprograma.
